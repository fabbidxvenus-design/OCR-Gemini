# Product Roadmap

## MVP (Current)

**Status:** Implemented and operational

### Core Features

- **OCR Workflow**
  - Camera capture with preview/retake
  - Image compression before OCR
  - OpenRouter Gemini OCR with multi-key fallback
  - Structured field editing
  - Raw text view

- **History**
  - IndexedDB local storage
  - Scan list with thumbnails
  - Search and filter (date, edited status)
  - Sort options (date, name)
  - Grid/list view toggle

- **Export/Share**
  - Excel export (single and multi-scan)
  - Multi-sheet workbook structure
  - Web Share API / file picker / download fallback
  - Text share and clipboard copy

- **Analytics/Settings**
  - KPI dashboard (total scans, cost, API key usage)
  - Top products list
  - Model tier selection (free/default/high)
  - Field categorization settings

## Phase 2 (Post-Launch)

**Target:** Q3 2026

### Backend Sync
- Add backend API for cross-device data sync
- User accounts and authentication
- Cloud storage for scan history

### Multi-User & Roles
- Team workspaces
- Role-based permissions (worker, supervisor, admin)
- Shared scan history

### UI/UX Improvements
- User feedback integration
- Performance optimization
- Accessibility enhancements
- Dark mode (if requested)

## Phase 3 (Future)

**Target:** Q4 2026+

- Offline queue (capture without internet)
- PWA offline caching
- Bulk operations
- Advanced analytics (charts, trends)
- Print functionality
- Multi-language UI support
